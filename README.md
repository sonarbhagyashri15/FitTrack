# FitTrack

## Gym Membership & Workout Plan Management Portal

FitTrack is a web-based Gym Membership and Workout Plan Management Portal developed using the Laravel 13 framework. The system is designed to simplify gym management by providing separate functionalities for administrators and users. It allows efficient management of membership plans, workout plans, workout videos, attendance, payments, and user progress through a responsive and user-friendly interface.

---

# Project Structure

## Admin Module

The administrator has complete control over the system and can perform the following operations:

- Manage Membership Plans
- Manage Workout Plans
- Manage Workout Videos
- Manage User Progress
- Manage Attendance Records
- Manage Payments
- Add, Edit and Delete Records
- View Dashboard Statistics

---

## User Module

Registered users can access the following features:

- Register and Login
- Purchase Membership Plans
- View Membership Details
- Watch Workout Videos
- View Attendance Records
- Track Personal Progress
- View BMI Information
- Access Workout Plans
